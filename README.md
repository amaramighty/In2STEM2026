# In2STEM 2026 Notebooks

This folder contains Binder-ready notebooks for the In2STEM galaxy project.

## Launching With Binder

After pushing this folder to a public GitHub repository, create a Binder link using:

```text
https://mybinder.org/v2/gh/<github-username>/<repo-name>/HEAD?urlpath=/tree/In2STEM_Project_1_Student.ipynb
```

Replace `<github-username>` and `<repo-name>` with the GitHub account and repository name.

## Files

- `In2STEM_Project_1_Student.ipynb`: worksheet notebook with guided code blanks.
- `In2STEM_Project_1_Day2_Start.ipynb`: notebook with Day 1 calculations filled in and Day 2 main-sequence tasks ready to complete.
- `In2STEM_Project_1_Trends.ipynb`: follow-up notebook with main-sequence classification completed and templates for investigating trends.
- `Presentation_Helper.md`: student guide for planning the final project presentation.
- `data/low_z_sample.csv`: reduced teaching sample used by the notebooks.
- `data/low_z_trends_sample.csv`: richer reduced teaching sample used by the trends notebook.
- `binder/environment.yml`: Python environment used by Binder.

Teacher solutions and older legacy notebooks are kept locally only and are not included in the public Binder repository.

Binder sessions are temporary. Students should download their edited notebook at the end of the session if they want to keep their work.
